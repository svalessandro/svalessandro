## Projeto em destaque

**[Radar de Imóveis SP](https://github.com/svalessandro/radar-imoveis-sp-showcase)**: ferramenta em Java 17 que coleta os imóveis à venda pela Caixa no estado de São Paulo, estima o valor de mercado com base em anúncios reais e calcula a margem de revenda. O resultado é publicado em um [painel online](https://svalessandro.github.io/radar-imoveis-sp-site/).

O código completo é privado (contém dados do meu negócio). A vitrine pública mostra arquitetura, metodologia e decisões, e posso mostrar o código em entrevista.
